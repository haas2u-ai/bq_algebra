The BQ algebra, one matrix product at a time

In the BQ-Pauli algebra a physical four-vector is four real coordinates on a basis of 2×2 complex matrices, A = a0T̂ + a·K̂. Multiplying such vectors is ordinary matrix multiplication, and the algebra sorts every product into its own channels. These three interactive models build that up step by step, and every result on them is computed live from the explicit matrices.

Reproduce in Python

The web pages compute in JavaScript. The folder py_sources holds an independent Python implementation with SymPy: it forms every product as an explicit 2×2 matrix product, decomposes it on the eight basis elements and checks the channel rule exactly, by simplifying the difference to zero.

  • bq_pauli_table.py · the 64 basis products against the paper’s table
  • bq_bilinear.py · the channels of ATB, all 169 pairs
  • bq_triple.py · the four channels of D(ATB), all 2197 triples
  • bq_core.py · basis, four-vectors, operator order, channel rules

Only Python 3 and SymPy are needed. A four-gradient acts on everything to its right; when it stands last, the product is evaluated on a test field ψ.

# get the code and install SymPy
git clone https://github.com/haas2u-ai/bq_algebra
cd bq_algebra/py_sources
pip install -r requirements.txt

# step 1: the multiplication table
python bq_pauli_table.py
python bq_pauli_table.py sI sJ

# step 2: one bilinear, then all pairs
python bq_bilinear.py R P
python bq_bilinear.py --all

# step 3: Maxwell and the Lorentz force
python bq_triple.py D D A --c1zero
python bq_triple.py J D A --c1zero
python bq_triple.py --examples

Conventions used throughout

All coordinates are real; the imaginary unit sits in the basis element T̂ = i1̂, so the Lorentz signature enters through the basis and not through index lowering. The space-time basis T̂, Î, Ĵ, K̂ and the spin-norm basis 1̂, σ̂I, σ̂J, σ̂K together span the full biquaternion algebra; a product of two space-time vectors always needs both.

The superscript T is the BQ time-reversal operation, AT = −a0T̂ + a·K̂: not the matrix transpose, not conjugation and not multiplication by T̂. In every product the left factor stands to the left, so a four-gradient on the left acts on what follows it.

Each model computes its results from the explicit 2×2 matrices and shows a numerical check of the stated rule; the Python sources repeat every product as an exact symbolic check. The BQ definitions in the papers remain authoritative; pages and scripts are a reproducibility aid.
